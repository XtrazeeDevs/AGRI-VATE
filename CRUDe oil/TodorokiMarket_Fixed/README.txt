TODOROKI MARKET - FIXED WINDOWS APP

1. Extract this ZIP to a normal folder.
2. Double-click TodorokiMarket.exe.
3. The app starts a local marketplace and opens it directly in Microsoft Edge,
   Google Chrome, Firefox, or Brave if one is installed.

This version avoids the Windows Shell URL-association method that can cause
"Class not registered" errors.

No PHP, XAMPP, MySQL, CMake, Visual Studio, Python, Node, or Git is required.

The app stores data in data.json and product photos in the uploads folder.
Keep the EXE, data.json, and uploads folder together.

TODOROKI MARKET - STANDALONE WINDOWS APP

Run:
1. Extract the ZIP to a normal folder such as Documents or Desktop.
2. Double-click TodorokiMarket.exe.
3. Your default browser should open Todoroki Market automatically.

If the browser does not open, open this file after starting the app:
  todoroki.log
It records startup errors and the local address used by the app.

NO Git, CMake, Visual Studio, PHP, XAMPP, or MySQL is required.

The app stores its database in data.json and uploaded product photos in the uploads folder beside the EXE.
Keep the EXE and uploads folder together.

Features:
- Register/login
- Any user can sell items
- Upload JPG/PNG/WebP product photos
- Product categories, prices, stock and descriptions
- Search marketplace
- Shopping cart
- Checkout and orders
- Seller listing management
- Persistent local data

The app runs a small local web server and uses your existing browser as its interface. It is a single Windows executable and has no external runtime dependencies.
